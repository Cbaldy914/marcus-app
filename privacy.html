Privacy Policy

Last updated: October 8, 2026

Marcus is a personal assistant used only by its owner. It isn't offered to the public.

What it accesses

With the owner's consent, Marcus uses Google APIs to read and manage the owner's own Google data, such as Gmail, Calendar, Drive, and Contacts. It doesn't access anyone else's account.

How data is used and stored

  • Data is used only to carry out tasks the owner asks for.
  • OAuth tokens are stored only on the owner's own computer.
  • Data is never sold, shared with third parties for advertising, or used to train models.

Marcus's use of information received from Google APIs complies with the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from Google Account permissions.
